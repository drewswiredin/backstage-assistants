# Screenshots & assets

Drop image assets here. They're referenced by **absolute raw URL** (pinned to the
release tag) from the project README and the marketplace metadata, so they render
on npm, GitHub, and the in-product Extensions catalog. (Relative paths do **not**
render on the npm package page.)

Expected files (referenced at the `v1.0.0` tag):

| File | Used by | Notes |
| --- | --- | --- |
| `icon.png` | directory entry, Extensions `spec.icon`, README | square logo (e.g. 256×256) |
| `chat.png` | README, Extensions gallery | the chat side panel |
| `editor.png` | README, Extensions gallery | the assistant admin editor |

After adding/replacing images, bump the `v1.0.0` tag in the raw URLs when you cut
a new release.

# Security

## Supported versions

Security fixes go to the latest release of each published package:

- `@drewswiredin/backstage-plugin-assistants`
- `@drewswiredin/backstage-plugin-assistants-backend`
- `@drewswiredin/backstage-plugin-assistants-backend-module-semantic-search`
- `@drewswiredin/backstage-plugin-assistants-common`

Older versions receive no fixes; upgrade to the latest release.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on
[the repository](https://github.com/drewswiredin/backstage-assistants/security/advisories/new).

Include the affected package and version, a description of the issue, and
steps to reproduce.

## Response

You get an acknowledgement within a few days and a fix or a mitigation as soon
as one exists. Reports are handled privately until a fix is released, after
which the advisory is published with credit to the reporter.

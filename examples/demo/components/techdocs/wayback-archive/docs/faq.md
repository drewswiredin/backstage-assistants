# FAQ

**How far back does it go?** Snapshots exist from 2001 for popular sites;
long-tail pages are captured when someone requests them.

**Can a site opt out?** Yes. Owners can exclude their site through the
removal request form; exclusions take effect within a day.

**Why is a snapshot missing images?** Images are captured separately and
sometimes later; the page shows what was captured closest in time.

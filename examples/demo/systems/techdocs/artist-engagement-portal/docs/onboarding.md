# Onboarding to team-a

1. Join `#artists-help` and `#team-a`.
2. Get read access to **artists-db** replicas through the access request form
   ("artists-db read, staging").
3. Run www-artist locally with `yarn start`; it uses staging artist-lookup by
   default.

## Things to know early

- Never cache artist images by name; names change, ids don't.
- Insights numbers are under embargo until 06:00 UTC each day; the site hides
  today's partial numbers.
- Support questions from artists arrive through the artist support queue,
  triaged by the on-call engineer each morning.
